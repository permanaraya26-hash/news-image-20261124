## How it works

`draw.py` (Python 3, Pillow only) draws the front page deterministically:
run it twice and the PNG is byte-identical. `main.ts` (Node 22, stdlib only)
copies `entry.png` to `/output/entry.png`, as the competition requires.

```sh
python3 draw.py   # writes entry.png (1024x1024 PNG, < 1 MiB)
```

Every story was checked against a major outlet for a 24 November 2026 date;
events from earlier days appear only as updates first reported on 24 November,
labelled as such. See `NOTES.md` for the leaderboard study and the full
story list with sources.
